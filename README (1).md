# MediLedger 2.0 — Blockchain Healthcare Platform

A blockchain-based electronic health records (EHR) platform with multi-role dashboards for Patients, Doctors, and Admins.

## Project Structure

```
mediledger/
├── index.html        # Main entry point
├── css/
│   └── main.css      # All styles (design tokens, components, layouts)
├── js/
│   └── app.js        # Application logic (state, navigation, data, UI)
└── README.md
```

## Features

- 🔐 Multi-role authentication (Patient, Doctor, Admin, Researcher)
- 🏥 EHR Studio — Create and manage electronic health records
- ⛓ Blockchain Explorer — View transactions and smart contract activity
- 👤 Patient 360° — Full patient profile with vitals and history
- 🔄 Interoperability Hub — FHIR R4, HL7, DICOM integrations
- 📊 Analytics & AI — Drug interaction checks, risk scoring
- 📋 Patient Registry — QR code generation, ledger view
- 🛡 Zero-Knowledge Proof authentication

## Usage

Open `index.html` in any modern browser. No build step required.

## Demo Credentials

Select any role on the login screen, enter any email, and click **Authenticate Securely** to access the role-specific dashboard.
